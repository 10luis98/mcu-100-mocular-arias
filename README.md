# MCU-100 Modular (Arias)

Entorno de práctica en KiCad para diseño modular con el módulo **MCU-100 (LQFP-100)** de Hellen-One.

## Archivos del Proyecto
- `mcu-100-modular.kicad_pro`: Archivo de proyecto KiCad.
- `mcu-100-modular.kicad_sch`: Esquemático principal.
- `mcu-100-modular.kicad_pcb`: PCB base listo para diseñar y rutear.
- `lib/`: Librería local con el símbolo y huella del módulo `mega-mcu100` (Hellen-One).
- `sym-lib-table` y `fp-lib-table`: Tablas de librerías vinculadas para cargar los componentes automáticamente en KiCad.
